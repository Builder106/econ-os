EconOS desktop

EconOS runs one agent-based economy that every visitor shares. Consumers sell labor and buy goods, producers hire and set prices, and reinforcement-learning policies drive both. This tiling desktop streams the kernel's wage, price, inequality and agent balances every half second. Anyone can inspect the run from the shell; a session that holds the admin token can change the tax rate, apply wage or price shocks, redistribute the treasury, or pause and reset the kernel, and every other viewer sees the change on the next tick.
